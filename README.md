## 📌 Executive Summary

**ACE (Agentic Commerce Engine)** is an innovative web application developed for the **Razorpay Summer Internship 2026 Submission**. Designed with a futuristic dark-space visual theme, ACE demonstrates how Agentic AI elevates traditional e-commerce into an autonomous, user-centric shopping ecosystem.

---

<!-- THEMATIC EXPLORATION: AI GROWTH & AGENTIC COMMERCE -->
## 🤖 AI Growth & Agentic Commerce

The e-commerce sector is transitioning from static, search-based storefronts to **Agentic Commerce**—where autonomous AI agents actively understand user intent, adapt in real-time, and execute shopping workflows with minimal friction.

* **Intent-Driven Interactions**: Replaces complex UI navigation with direct voice queries and intelligent context parsing.
* **Autonomous Operations**: Automatically handles tiered pricing calculations, coupon application, and payment gateway routing.
* **Frictionless Consumer Journey**: Streamlines product discovery to final checkout within a single responsive view.

---

<!-- APPLICATION FEATURES & USER BENEFITS -->
## ✨ Key Platform Capabilities

* **🌌 Space-Themed Visual Experience**: Interactive particle loading screen featuring text-to-speech voice greetings.
* **🎤 Speech-Driven Product Search**: Integrated Web Speech API for natural language hands-free voice discovery.
* **🏷️ Smart Tiered Discounts**: Automatic dynamic savings calculations (10% off for orders above ₹1,000; 20% off above ₹3,000).
* **💳 Integrated Razorpay Checkout**: Fully functional test-mode payment gateway integration for seamless purchasing.
* **🎨 Responsive Cyberpunk Dashboard**: Modern dark-mode layout optimized for speed and accessibility.

## 🚀 How to Run the Project (Execution Guide)

Evaluators can run and test the application locally in just a few steps:

### **Prerequisites**
* Any modern web browser with **Web Speech API support** (Google Chrome, Brave, or Microsoft Edge recommended for voice features).
* Active internet connection (required to load external dependencies like FontAwesome icons and Razorpay SDK).

### **Execution Instructions**

1. **Clone the Repository:**
   ```bash
   git clone [https://github.com/Yogesh16-c/ACE250]

```

2. **Navigate to Project Directory:**
```bash
cd ace-agentic-commerce

```


3. **Launch the Application:**
* **Option A (Direct Launch)**: Double-click the `index.html` file to open it directly in your browser.
* **Option B (VS Code Live Server)**: Open the project folder in VS Code, right-click `index.html`, and select **Open with Live Server**.


4. **Testing Payment Execution (Optional):**
* To test custom Razorpay parameters, update the `key` field inside `processCheckout()` in `index.html`:
```javascript
const options = {
    "key": "rzp_test_YOUR_RAZORPAY_KEY",
    ...
};

```
